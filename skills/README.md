# Rocq factual-skill snapshot

This directory contains a facts-only snapshot of the 14 Rocq-related skill
packages retained from the current installation. The retained documents
describe Rocq, Stdlib, stdpp, Dune, and selected trust, specification, search,
diagnostic, and proof-language behavior. Workflow, delegation, agent-policy,
and MCP-interface packages are not included.

The live skill installation remains outside this repository.
