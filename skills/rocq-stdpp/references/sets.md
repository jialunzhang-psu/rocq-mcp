# stdpp Set and Domain Facts

Domain declarations include `elem_of_dom`, `elem_of_dom_2`,
`not_elem_of_dom`, `not_elem_of_dom_1`, `not_elem_of_dom_2`, `dom_empty`,
`dom_insert`, `dom_delete`, and `dom_union`.

`set_unfold` changes hidden set membership expressions into their propositional
forms. `set_solver` operates on the resulting supported set-algebra goals.
